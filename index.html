Personal Project · Android & IoT Complete

Smart Plant Watering System

An automated plant watering system combining an Android application, ESP8266 controller, custom PCB and MQTT communication. Demonstrates end-to-end integration across software, networking, embedded hardware, and physical devices.

  • Monitor soil moisture readings remotely
  • Control water pump operation across different Wi-Fi networks
  • Configure automatic threshold-based watering schedules
Java Android Studio ESP8266 Arduino MQTT PCB Design
App Telemetry Screen

Hardware Integration

ESP8266 Wi-Fi microcontroller interfacing with soil moisture sensors and pump relays via custom PCB circuitry.

Software Stack

Native Android Java client connected over MQTT broker protocol for bi-directional remote telemetry.

Key Features

Real-time moisture updates, remote manual override, and autonomous threshold triggers.
